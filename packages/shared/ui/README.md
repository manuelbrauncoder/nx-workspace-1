# ui

The UI building blocks every app uses: wrappers around Spartan (`ui/`), the Signal Forms controls (`form-controls/`), `app-async-content`, `app-failure-alert`, the theme and language toggles and their shared texts (`i18n/`). The only lib that imports Spartan, `@ng-icons` and Tiptap. Imported through `@shared/*`, e.g. `@shared/ui/button/button`.
