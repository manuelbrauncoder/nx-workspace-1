# helm

The Spartan Helm components, generated by the Spartan CLI in the style vega. Treated as vendor code: Prettier and ESLint skip it, only `ui` imports it.

| Item    | Value                                                        |
| ------- | ------------------------------------------------------------ |
| Folder  | [packages/shared/helm-vega](../../packages/shared/helm-vega) |
| Alias   | `@spartan-ng/helm/*`, e.g. `@spartan-ng/helm/button`         |
| Tags    | `type:helm`, `scope:shared`                                  |
| Used by | `ui`                                                         |

## Spartan styles

Spartan ships several styles (`nova`, `vega`, `lyra`, `maia`, `mira`, `luma`). The style is baked into the generated code, so each style is its own lib with the same API. `tsconfig.base.json` maps `@spartan-ng/helm/*` to `helm-vega`, an app with another style maps it in its own `tsconfig.json`. A new style lib comes from:

```bash
node tools/scripts/add-helm-style.mjs nova
```

A new component:

```bash
pnpm nx g @spartan-ng/cli:ui <name> --angularCli=true --directory=packages/shared/helm-vega
```

Remove the path the CLI adds to `tsconfig.base.json`, the wildcard covers it, and generate the component in every style lib. Details in [UI components](../frontend/ui-components.md#spartan-styles).
